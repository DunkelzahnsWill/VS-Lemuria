base. When every changed file lies under `record/`, the setup, build, smoke test and both uploads are skipped and
the check `build` passes. Every other pull request, every push to main and every manual run builds and tests in
full, as before. README's line on CI says so.

**Why.** G43: the smoke test fails by chance (the Motor's timing, the Death Focus check), and each failure held a

the PR would never merge (the setup list says so). Comparing against the merge commit's first parent, rather than
the PR's base commit, judges the change as it would land on main today.
