# Patch: the Mysteries smoke scenes start with their rooms empty of creatures and dropped items (G43, feature 9)

**Done.** `MysteriesTests.Room`, which every Mysteries scene builds first, now also removes every creature and
dropped item (anything but a player) inside the room it clears. Nothing outside the smoke test changes.

**Root cause, from the code.** A Focus aims as a cast does (`CastContext.Aim`): the game's ray returns a creature
before a block, and then the cast has no block. A Glittering Death crystal withers plants only, so with a creature
or a dropped item in the two open blocks between the Focus and its flower, the working is "Nothing" and the flower
stands: exactly the failed line of PR #33's run ("a Death Focus Nothing, the flower is flower-lupine-blue-free, 0
item(s)"). The machines scene stands at the surface with no walls or roof, so a wild animal of the world near spawn
can be there or not, run to run. I could not see that run's log, so this is the cause the code allows and the only
one I found; the next chance failures will show whether it holds.

**Why not another way.** Walls and a roof would change what the scene shows; clearing the room keeps every scene as
it was and only takes out what the world put there by chance. Scenes spawn their own creatures after Room, in
columns 20 blocks apart, so none of them is touched.

**Checks.** setup, build and smoke test pass ("a Death Focus Acted, the flower is gone").
