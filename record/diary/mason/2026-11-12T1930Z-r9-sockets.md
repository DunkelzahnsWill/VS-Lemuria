# R9 for an Awakened block's sockets (G16, feature 4)

**Done.** `SparkstoneClaims` answers the game's block access event, as Storage's does: with the claims switch off,
a stranger's use of a Free Awakened block inside a claim (setting a crystal into its sockets, taking one out) is no
longer refused by the claim. Breaking and placing stay as the game rules them, and with the switch on nothing
changes. It opens only a Free block (the class `BlockSparkstone` itself): a block carved into a machine, the Memory
among them, is feature 8's (`BlockMachine`), and feature 8's own patch opens it. The inquisitor's doubt at
6327853 was that the first version opened feature 8's blocks in play from feature 4's patch; this one does not. The new smoke test `sparkstone test claims`
calls the game's own test as it ends for a stranger in a claim, with the switch on and off.

**Why.** Feature 4's brief, Claims, and R9. The game tests a claim before a block's own interaction, so the socket's
own check could not open anything (G16).

**Why not another way.** The Storage pattern needs no Harmony and lifts only the use, after the game's claim said
no; other mods still get their say through the game's `CanUseBlock`.
