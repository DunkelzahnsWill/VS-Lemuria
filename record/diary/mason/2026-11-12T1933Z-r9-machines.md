# R9 for machines, the Memory, the Control Shelf and the rod's making (G16, feature 8)

**Done.** `MachinesClaims` answers the game's block access event, as Storage's does. With the claims switch off, a
stranger's use inside a claim is no longer refused by the claim for: any machine (a `BlockMachine`, the Memory
among them: setting crystals into its sockets or magazine and taking them out), any Control Shelf (putting items
on and taking them off), and a placed Unaligned crystal while the hand holds the polished rock that makes it a
Crystal Rod. Breaking and placing stay as the game rules them, and with the switch on nothing changes. The rod's
making still asks the switch for building itself (`BlockBehaviorRodMaker.Make`), which with the switch off lets it
through. The smoke test `machines test claims` calls the game's own test on a shelf, a Gather block and a Memory,
and asks which held items open a placed crystal.

**Why.** Feature 8's brief, Claims, "Uses by hand", and R9 (G16).

**On the crystal.** The placed crystal is feature 1's block, but the crystals brief hands the rod's making to feature
8's brief, and the behaviour that makes the rod is feature 8's (`Lemuria/Machines/BlockBehaviorRodMaker.cs`). The lift
opens a crystal only to a hand that holds polished rock, so it opens nothing of feature 1's own: any other click
on a crystal is left as the game answered it.

**Also.** PR #84 was narrowed to a Free Awakened block, so the machines and the Memory are this patch's, not
feature 4's.
