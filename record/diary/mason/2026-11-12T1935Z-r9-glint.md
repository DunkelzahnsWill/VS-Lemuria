# R9 for the glint (G16, feature 9)

**Done.** `MysteriesClaims` answers the game's block access event, as Storage's does: with the claims switch off, a stranger's
use of a `BlockGlint` inside a claim (setting a crystal into a Glint and taking one out) is no longer refused by the claim. Breaking and placing stay as the game
rules them, and with the switch on nothing changes. The new smoke test `mysteries test claims` calls the game's own test
as it ends for a stranger in a claim, with the switch on and off.

**Why.** Feature 9's brief, Claims, and R9. The game tests a claim before a block's own interaction, so the block's
own check could not open anything (G16).

**Why not another way.** The Storage pattern needs no Harmony and lifts only the use, after the game's claim said
no; other mods still get their say through the game's `CanUseBlock`. It lifts only this feature's own block, so
the patch changes no other feature in play.
