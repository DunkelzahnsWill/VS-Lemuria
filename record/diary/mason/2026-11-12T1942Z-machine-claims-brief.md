# The machines brief takes the owner's "Fix" for G58 and G61

**Done.** The machines brief, Claims, now says what a machine's fire and its containers do, by the owner's word of
19:35Z (R27: "G58.) Fix G61.) Fix"):
- A fire a machine sets on a face is its carver's, so the game holds its spread at any claim the carver may not
  build in, as it does for a fire set by hand. Where the game does not know the carver, the machine sets no fire on
  a face and still lights what can be lit.
- With the switch on, a container inside a claim is a machine's only if the machine stands in that same claim
  (the shelf's input and output, a machine's yield container, a reclamation plate's). One left out counts as no
  container at all.
The evocations brief's sentence on a machine's fire points the same way, since the code that names a fire's starter
is feature 6's (`Effects.SetFire`). "What to try" gains item 17, and open question 5 records the answer.

**Why.** Both change what a player sees, so the briefs change first (rule 2), then the patches.

**Why not another way.** For a carver the game does not know, lending the fire to the nearest player online would
hold it at that stranger's claims, not the carver's; setting no fire keeps the rule. A left-out container is treated
as missing, not as full, so a shelf waits as for missing stock and a yield falls where the work was, behaviour the
brief already has.

names an entry by the time it was written, and these ran ahead of the clock (the review thread, 19:34Z).
